# 🏥 MediGest – Sistema de Citas Médicas

## 📌 Descripción
MediGest es un proyecto de software diseñado para facilitar la gestión de citas médicas, permitiendo a los pacientes agendar, consultar y cancelar citas de manera sencilla.

## 🎯 Objetivo
Planificar y documentar un sistema de citas médicas, aplicando buenas prácticas de calidad del software y control de versiones mediante GitHub.

## ⚙️ Funcionalidades principales
- Registro e inicio de sesión de usuarios.
- Agendamiento y cancelación de citas.
- Consulta de disponibilidad médica.
- Gestión de horarios de los médicos.
- Notificaciones y recordatorios de citas.

## 👥 Usuarios del sistema
- **Pacientes:** solicitan y administran sus citas.
- **Médicos:** consultan sus agendas.
- **Administradores:** gestionan usuarios y horarios.

## 📋 Requisitos principales
1. **RF-01:** Permitir el registro de pacientes.
2. **RF-02:** Permitir agendar citas médicas.
3. **RF-03:** Consultar horarios disponibles.
4. **RF-04:** Permitir cancelar citas.
5. **RF-05:** Enviar notificaciones de citas.

## 👨‍💻 Equipo de trabajo
- **Integrante 1:** Líder del proyecto.
- **Integrante 2:** Responsable de documentación.
- **Integrante 3:** Gestor de cambios y auditor SQA.
